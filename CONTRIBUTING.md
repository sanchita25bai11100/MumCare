# Contributing to MumCare

Thank you for your interest in contributing to MumCare.

MumCare is an academic software project exploring AI-assisted maternal healthcare and responsible digital health technology.

## Development Principles

Contributions should prioritize:

- User safety
- Privacy
- Accessibility
- Reliability
- Clear documentation
- Responsible AI practices

## Before Contributing

1. Review the project documentation.
2. Understand the existing architecture.
3. Avoid committing API keys, credentials, or sensitive health information.
4. Keep changes modular and well documented.
5. Add or update tests when modifying application logic.

## Pull Requests

A good pull request should:

- Clearly describe the change.
- Explain why the change is needed.
- Avoid unrelated modifications.
- Include testing information where applicable.

## Healthcare Safety

MumCare is not intended to replace qualified healthcare professionals.

Any feature involving health-related recommendations should be designed with appropriate safety boundaries and human oversight.

## Code Quality

Please keep code:

- Readable
- Modular
- Consistent
- Documented where necessary
- Easy to test

Thank you for helping improve MumCare.
